# TestingEdu26

- **`plugin/`** — TestCompass IntelliJ plugin source, build configuration, and tests.
  See its README for build and API configuration instructions.
- **`analysis/study_analysis.ipynb`** — analysis of activity allocation,
  test-suite quality, survey ratings, and redundant test methods.
- **`analysis/data/`** — de-identified numerical analysis inputs. Demographics are aggregated.

- **`tasks/`** — deidentified tasks and instructions used in the study: MarsRover and
  BowlingScoreKeeper Java projects, starter JUnit tests, participant instructions,
  and an archival consent form. Identifying details and clickable links have been
  removed or generalized; Java source and starter tests are unchanged.
